## 接口自动化导入功能调整 - 实现方案（已补充环境命名/去重）

### 需求
点击导入按钮选择格式后不再直接进入文件选择，而是弹出导入窗口：
1. **导入格式**下拉（默认显示刚才选择的格式，可二次修改）
2. **导入文件区域**（点击唤出 Windows 文件选择）
3. **开关1「去除 URL 里的 http://...com」**：开->接口只保留路径（现有行为）；关->保留完整 URL
4. **开关2「创建环境」**：开->提取接口路径前缀域名作为环境 base_url，环境名称统一为「环境1（导入）、环境2（导入）...」，按导入文件中域名数量创建，**一种域名只创建一次，切勿重复创建**；关->不操作
5. 右下角「开始导入」按钮

### 环境创建规则（与用户确认）
- 仅对识别到的含 `scheme://netloc` 的域名提取 origin 作为 base_url，去重。
- 创建前查询项目内已有 `ApiEnvironment`：**已有相同 base_url 的则跳过**（按域名去重，全项目唯一，避免重复创建）。
- 命名 `环境N（导入）`，N = 项目内已有名为 `环境X（导入）` 的最大 X 之后递增，保证名称唯一（满足 `unique_together=['name','project']`）。
- verify_ssl：https 域名设 True，否则 False；is_active=True；无变量的空环境。
- 域名来源：OpenAPI3 `servers[].url`、Swagger2 `host`+`schemes`、Postman/HAR/Insomnia/cURL 完整 URL（被转换器折叠进 paths 后仍含 scheme/netloc）。纯路径格式（Apifox/Apipost/YApi/Apidoc/Apizza/Eolink）无域名则不创建。
- 返回结果新增 `created_environments: [{id,name,base_url}, ...]`。

### 关键现状（来自探查）
- 当前后端**始终去域名**：`_normalize_import_path`(exchange.py:395) 与 `_openapi_server_path`/`_swagger_base_path`(openapi.py:626/645) 只保留 path。
- 模型 `ApiInterface.url` 为 `TextField`，无校验，可存完整 URL。
- 7 个导入测试均断言 url 为纯路径 -> **开关1 默认开（去域名=现有行为），后端新参数带默认值，现有测试不受影响**。
- 仅 `views.py:import_openapi` 与 `InterfacesPanel.vue` 调用该流程。

### 实现

#### A. 后端
1. **exchange.py**：
   - `_normalize_import_path` 增加 `keep_full_url=False` 形参：True 时含 scheme/netloc 的 URL 保留 `scheme://netloc+path`（去 query）；False 维持现状。`_add_operation` 透传该参数（默认 False 向后兼容）。
   - 新增 `extract_document_base_urls(document)`：从 servers/Swagger host+schemes/paths key 收集去重 origin 列表。
2. **openapi.py**：`import_openapi_interfaces` 新增 `strip_base_url=True`、`create_environments=False`：
   - `strip_base_url=False` 时，`_iter_operations` 改用保留 origin 的前缀（OpenAPI3 取 servers[0].url 的 scheme+netloc+path；Swagger2 取 host+basePath），使 `payload["url"]` 保留完整 URL。
   - `create_environments=True` 时：调 `extract_document_base_urls` 取 origin，逐个查重（按 base_url）后创建 `ApiEnvironment`，命名 `环境N（导入）` 接续已有最大编号，收集到 `created_environments`。
   - 默认值保证现有行为不变。
3. **views.py**：`import_openapi` 从 `request.data` 读 `strip_base_url`(默认True)、`create_environments`(默认False)，布尔解析后透传。

#### B. 前端
4. **interfaceService.ts**：`importApiDocument(file, sourceType, options?)` 增可选 `{strip_base_url?, create_environments?}` 附加到 FormData；`OpenApiImportResult` 增 `created_environments?`。
5. **InterfacesPanel.vue**：新增导入弹窗：
   - `handleImportTypeSelect` 文件类型不再直接 click 文件输入，改为打开弹窗并设初始格式、清空已选文件。
   - 弹窗：`a-select` 格式（可改）、可点击文件区（触发隐藏 input.click()，选中显示文件名）、`a-switch` 开关1(默认开)/开关2(默认关)、右下角「开始导入」按钮。
   - `handleImportFileConfirm`：校验文件->调 `importApiDocument(file, 格式, {strip_base_url:开关1, create_environments:开关2})`->成功提示(含新增环境数)->刷新->关闭重置。
   - 复用现有暗/亮色 modal 与 switch 样式。

#### C. 测试
6. **tests.py**：新增 `strip_base_url=False` 时 url 含 origin；`create_environments=True` 时按域名创建环境、重复导入跳过、命名接续编号；默认参数下行为不变。
